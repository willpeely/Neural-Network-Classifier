Project overview

End-to-end image classification pipeline

The project covers model architecture design, CIFAR-10 data preparation, data augmentation, training, validation, learning-rate scheduling and final evaluation on unseen data.

01

Custom CNN

Five convolutional blocks progressively increase feature depth from 32 to 512 channels before classification through fully connected layers.

02

Regularisation

Batch normalisation, dropout, weight decay and data augmentation are used throughout the training pipeline to improve generalisation.

03

Adaptive Learning

Adam optimisation is combined with ReduceLROnPlateau so the learning rate decreases when validation accuracy stops improving.

Architecture

Progressively deeper feature extraction

The model increases channel depth while reducing spatial dimensions through max pooling before mapping learned features onto the ten CIFAR-10 classes.

Training

Built to generalise

Data augmentation

Colour jitter, random rotation, horizontal flipping and random crops increase the variation seen during training.

Optimisation

Adam is used with a learning rate of 0.001 and weight decay of 0.0001, alongside cross-entropy loss.

Validation feedback

A 90/10 training-validation split is evaluated every epoch, with validation accuracy driving the adaptive learning-rate scheduler.
