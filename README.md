# Neural Network Classifier

This project focused on using PyTorch to create a neural network to classify images in the CIFAR-10 dataset.
Designed a deep learning architecture using 5 convolutional layers, 2 fully connected layers, batch normalization, dropout, and ReLU activations to optimise generalisation.
Implemented training pipeline with data augmentation, learning rate scheduling, and regularization to prevent overfitting training data.

View the code here - https://willpeely.github.io/Neural-Network-Classifier/
